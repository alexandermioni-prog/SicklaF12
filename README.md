# Sickla F2012

Hemsida för Sickla IF F2012. Statisk sida (ingen byggprocess) som hostas på Netlify.

- `index.html` – själva sidan. Innehållet läses in från `content/*.json`.
- `content/` – nyheter, matcher, träningstider, ledare och sponsorer.
- `admin/` – ledarinloggen (Decap CMS). Ledare loggar in på `/admin/` med GitHub-konto.
- `img/` – bilder. Bilder som laddas upp via ledarinloggen hamnar i `img/uploads/`.

Lagbilden 2026 är tagen av idrottsfoto.com.
